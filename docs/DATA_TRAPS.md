# Data traps

Record dataset surprises here (missing sensors, unit changes, upgrades, timestamp issues, duplicate rows).

| Date | Table / field | What we found | How we handle it | Owner |
|------|---------------|---------------|------------------|-------|
| 2026-10-15 | Annual 2018 station coverage | One alarm event uses `StationNr=91` (2018-09-05 21:04:41), with no corresponding selected sensor records. Monthly sensor files also include the year-end midnight boundary at 2019-01-01. | Preserve station 91 on a separate alarm-only sheet and retain the boundary readings; do not interpret station 91 as an additional turbine. | Data preparation |
| 2026-10-15 | Monthly SCADA boundaries | Adjacent files overlap at midnight. October pressure readings have fewer decimal places than matching boundary rows in adjacent months. | Merge numerically equivalent duplicate keys (`rel_tol=1e-9`, `abs_tol=1e-8`), keeping the longer value representation; count separately in `rounded_duplicates_merged`. Larger conflicts still stop export. | Data preparation |
| 2026-10-15 | October 2018 pressure timestamps | `tblSCTurPress_2018_10.csv` uses day/month/year timestamps such as `1/10/2018 0:00`, unlike the ISO timestamps in other months. | Parse slash-separated dates explicitly as day-first, normalise to ISO, and test cross-month joins. | Data preparation |
| 2026-10-15 | 2018 monthly coverage in `data/raw/` | Turbine, temperature, and alarm tables have all 12 months; `tblSCTurPress_2018_01.csv` and `tblSCTurPress_2018_02.csv` are absent. | Combine available files without dropping rows; January/February pressure readings remain blank in `turbines_2018.xlsx`. | Data preparation |
| 2026-10-15 | Windows processed workbook access | Moving output out of Python 3.13's private temporary directory retained an ACL without the user's normal access permissions. | Restore inherited permissions on the affected workbook; publish future workbooks through a fresh file in the destination folder. Add a Windows ACL regression test and an independent Excel-library read test. | Data preparation |
| 2026-10-15 | June 2018 temperature headers | Requested temperature names have a `wtc_` prefix. `wtc_InvUpTmp_mean` and `wtc_TrafoTMa_mean` are absent. | Preserve source names; export absent columns as blanks and list them in the export report. | Data preparation |
| 2026-10-15 | June 2018 alarm keys/timestamps | Alarms use `StationNr`, `TimeOn`, `TimeOff`, and `Alarmcode`; starts often fall between sensor timestamps. | Map `StationNr` to `StationId`; preserve exact start times as separate rows and retain end times in `AlarmEvents`. No forward-filling or interval assumptions. | Data preparation |
