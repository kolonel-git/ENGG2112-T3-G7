## 4. Dependencies

- Labels need the cleaning layer and the `tblDailySummary` loader; the harness needs labels only for its integration test.
- Normal-behaviour residual features must be computed before the O2 feature table; both use train-year fits only.
- Upgrade analysis needs `Hill_of_Towie_AeroUp_install_dates.csv`; interpreting `TimeErr` needs the data dictionary; both are Zenodo metadata files not yet in the repo. The upgrade analysis is cut from the sprint.

## 5. Risks and mitigations

| Risk | Mitigation |
|------|------------|
| `TimeErr` meaning unverified | Cross-check against SCADA-derived stops (target B); get the data dictionary; report both targets |
| Few events per fold, especially in leave-one-turbine-out | Always report positive counts; turbine bootstrap; merge folds or group CV if counts are too small |
| Cross-year drift (hydraulic pressure steps, bearing temperature drift) | Time-based split; year-shift stress test; per-year feature checks |
| No measured active power | Rpm-vs-wind curve proxy and daily energy, documented deviation (D-011) |
| Possible anemometer faults on a few turbine-years | Flag and test with and without those turbine-years |
| Data leakage | Train-only fits, window features end at t, leakage test in the suite |
| Undocumented alarm codes (21% of the log) | Not used as targets; tested only as a discovery aid for stops |
| Time | Five days left: one frozen test run on day 3, daily checkpoints, an explicit cut order (section 3) |

## 7. Known limitations to state in the report

- No measured active power or failure/maintenance records in the open data; "degradation" and "failure" are inferred from fault time and SCADA behaviour.
- Alarm descriptions exist for only 12 codes; most of the log is undocumented.
- Positive windows cover 42 to 49% of days, so a random score reaches recall 0.79 to 0.84 at the 1-false-alarm budget and no baseline beats that floor. Report PR-AUC against the random floor and episode-level results, not recall at the budget alone (D-020).
- The NBM indicator drifts between train and validation years (standardised mean -0.92 to +0.61) and is a weak early-warning signal (D-057).
- 2019 temperature and pressure tables are missing; 2022-08, 2022-09 and 2025-09 are outage months.
